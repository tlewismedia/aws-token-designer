# `versions.tf` — Dev provider constraints

**Purpose:** Pin Terraform and the providers used by the dev root.

## What it declares

- `required_version >= 1.10` — native S3 state locking.
- `hashicorp/aws ~> 5.0` — AWS resources.
- `hashicorp/archive >= 2.0` — used indirectly by modules that zip Lambda bundles (`archive_file`).

## Teaching notes

- **`archive` is a provider, not a CLI tool.** It lets Terraform create zip files from local sources at plan/apply time.
- **Pin at the root, not only in modules.** Modules declare their own constraints, but the root’s `versions.tf` is the final say for the environment.
- **Lockfile:** `.terraform.lock.hcl` (generated by `init`) records the exact provider builds. Commit it.
- **Upgrades:** `terraform init -upgrade`, read the plan. A provider minor bump can change default behaviour.
